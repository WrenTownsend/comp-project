* how the rule is used
** no | rules
check for first thing if not found return null
check for next thing if not found throw error
all things checked return new node
example: assign_stmt, if_stmt
** one or more rules (| options start with same token)
check for thing
if don't find thing return null
if find thing check for next thing
if don't find thing return last thing
examples: stmts, top_elems
** or rules
check for things if something matches return new node
if not return null
examples: stmt,
** rule
check if first token is present if not return null

* LL(1) parser rules
thing = a, b | a, c | d, b | d, c
this is impossible
rule can only have one set of options with the same starting token

if I dont allow multiple options and only use {} it solves this problem

for every option {
        if element matches {
                next element
                for every element in list of elements {
                        if element matches {
                                next element 
                        } else {
                                throw error "expected token after previous token"
                        }
                }
                return new node
        }
}
